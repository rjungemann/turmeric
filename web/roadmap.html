The Turmeric
Roadmap

An overview of planned features, ongoing work, and recently completed milestones. This page reflects the current state of the project's design documents.

Core Language

Type System & Syntax
Currying
In Progress

Haskell-style partial application via a worker/wrapper pattern. Phases CY0--CY3 are complete; CY4 (effect row integration and rank-2 types) is pending.

Phases CY0-CY3 done • CY4 pending
Compound Type Annotations
Planned

Extends the :keyword syntax to support complex type expressions such as (-> A B), enabling richer type-level annotations on function arguments and return values.

Lazy Sequences
Planned

Iterator-based lazy sequences through the typeclass system, allowing memory-efficient processing of potentially infinite lists without eagerly allocating.

Dynamic Parameters
Planned

Racket-style dynamic parameters backed by thread-local storage. Provides a structured, safe alternative to global mutable state for implicit configuration passing.

Advanced Type System
Planned

A long-horizon investigation into features such as linear types, dependent types, session types, GADTs, and higher-kinded types -- evaluated for complexity, value, and phased rollout.

Feasibility study complete • implementation not started
Struct Inspection & Derive
In Progress

A derive-show macro that automatically generates Show typeclass instances from struct definitions, reducing boilerplate for debugging output.

Effects & Concurrency

Algebraic Effects
Effect Rows
In Progress

Typed effect rows track IO, mutation, exceptions, and custom effects through function signatures. Enforcement and propagation are being rolled out across multiple phases.

Core tracking in progress • full propagation pending
Generator Functions
Planned

Coroutine-style generator functions using algebraic effects. Enables yield-based iteration patterns without manual state machines or callbacks.

Self-Hosted Interpreter & Eval
Planned

A tree-walk interpreter written in Turmeric itself, exposing a public eval API and async REPL support for runtime code evaluation.

Tooling

CLI & Build System
tur CLI
Planned

A unified project management tool with tur new, tur run, and tur add subcommands for project scaffolding and dependency management.

Build & Test UX
Planned

Improvements to test runner output -- buffered display, progress indicators, and Raylib rebuild caching -- to reduce iteration time during development.

Source Layout Refactor
Planned

Reorganizes the src/ directory into a more maintainable structure as the codebase grows across compiler phases.

Performance Benchmarking
Planned

A structured benchmark suite comparing Turmeric against C, Clojure, Racket, and Python on standard algorithms to track performance regressions and improvements.

Interoperability

C & Native
CMake / CPM Integration
Planned

Two-way integration: Turmeric projects consuming CMake/CPM packages, and CMake-based projects consuming Turmeric libraries via generated CMake config files.

C DSL
Planned

An embedded DSL for writing C code with Lisp syntax from within Turmeric. Allows structured, programmatic generation and manipulation of C source at compile time.

GLSL DSL
Planned

An embedded DSL for writing GLSL shaders with compile-time validation, making it possible to author and compose GPU shader code from Turmeric programs.

Developer Experience

REPL & Editor
REPL Auto-Show
In Progress

Automatically displays Show typeclass results for evaluated expressions in the REPL, removing the need to manually wrap values in println calls.
