# Python packages the docs generators need.
#
#   python3 -m pip install -r tools/requirements.txt
#
# `just docs` (genguides.py / genspices.py) renders guide and spice markdown
# with this; without it the recipe stops with an install hint rather than
# half-generating the site and the docs pack.
#
# C-5 in docs/upcoming/security-audit-plan.md: pinned exactly, with hashes.
# This used to read `markdown>=3.4` -- a floor with no ceiling and no digest --
# and it is installed inside release.yml's `docs` job, which builds the
# turmeric-docs tarball the release publishes.  That made "whatever PyPI serves
# this morning" a build input of a released artifact.
#
# markdown 3.10 is the pin rather than the newest: it is the earliest release
# with NO runtime dependencies at all (3.9 and below carry a conditional
# `importlib-metadata` on Python < 3.10, and --require-hashes demands a hash
# for every transitive package on every interpreter that resolves it).  One
# package, two digests, no conditional edges.  Needs Python >= 3.10; CI pins
# 3.12 where it sets up Python at all.
#
# To bump: pick the version, then
#   python3 -c "import urllib.request,json; d=json.load(urllib.request.urlopen('https://pypi.org/pypi/markdown/<ver>/json')); [print(f['digests']['sha256'], f['filename']) for f in d['urls']]"
# Both digests are listed because pip picks the wheel or the sdist depending on
# the host, and --require-hashes checks whichever it actually downloaded.
markdown==3.10 \
    --hash=sha256:b5b99d6951e2e4948d939255596523444c0e677c669700b1d17aa4a8a464cb7c \
    --hash=sha256:37062d4f2aa4b2b6b32aefb80faa300f82cc790cb949a35b8caede34f2b68c0e
