(size c)))) ;; Efficient tree fold using algebraic effects defn fold-tree (f init tree) (match tree | Leaf => init | (Node v l r) => (f v (fold-tree f init l) (fold-tree f init r))) defn main () (let tree (Node 5 (Node 3 Leaf Leaf) (Node 8 Leaf Leaf)) (println (fold-tree + 0 tree))) ; => 16

Typeclasses

Polymorphism
that scales.

Define behavior once, use it everywhere. Turmeric's typeclass system handles dispatch at compile time — no virtual tables, no runtime cost.

Derive common typeclasses automatically, or write your own implementations with complete type inference.

typeclasses.tmrc
defclass (Show a) (show : (-> a Str)) deftype Color | Red | Green | Blue impl Show Color (defn show (c) (match c | Red => "red" | Green => "green" | Blue => "blue")) ;; Works for any type with Show defn print-all [Show a] (xs : List a) (for-each (fn (x) (println (show x))) xs) ;; Derive multiple classes at once (deftype Point (x : Float) (y : Float) [derive Show Eq Ord])

Algebraic Effects

Side effects,
tamed.

Declare what your functions can do, not how they do it. Handlers let you swap implementations — test, log, mock — without touching your core logic.

Compose effects freely. The type system ensures you never forget to handle one.

effects.tmrc
effect Db (query : (-> Str (List Row))) (insert : (-> Row Unit)) ;; Business logic — no mention of *how* Db works defn create-user (name email) (let existing (query (str "SELECT * FROM users WHERE email='" email "'")) (if (empty? existing) (insert {:name name :email email}) (error "user already exists"))) ;; Swap handler in tests — no mocking frameworks defn with-test-db (program) (handle program (query _ (resume [])) (insert _ (resume ())))

Get Started

Up and running
in minutes.

01 — Install
One command install
curl -sSf https://install.turmeric-lang.org | sh # or via Homebrew brew install turmeric

Installs the compiler, REPL, package manager, and language server. Supports macOS, Linux, and Windows.

02 — New Project
Scaffold a project
turmeric new my-project cd my-project turmeric run

Creates a project with sensible defaults, a package manifest, and a hello world entry point.

03 — Write Code
Your first function
defn greet (name : Str) : Str (str "Hello, " name "!") (println (greet "Turmeric"))

Types are inferred but can be annotated. The compiler catches errors before you run.

04 — Add Packages
Rich package ecosystem
turmeric add spice/http turmeric add spice/json turmeric add spice/postgres

The Spice registry hosts packages for HTTP, JSON, databases, parsing, and more — all with effect-typed APIs.
